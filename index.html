Opción recomendada: iframe (evita el bug de wpautop en WordPress)
WordPress a veces mete etiquetas <p> dentro del script y lo rompe. Con este método, el mapa vive en una página aparte alojada en GitHub Pages y en WordPress solo pegas una línea de iframe — inmune a ese bug.
Sube el .html descargado a tu repo visor-gpx, dentro de una carpeta /mapas/ (mismo proceso que con index.html). Luego pega el iframe en el bloque de código de WordPress.
El código del iframe aparecerá aquí tras generarlo.
